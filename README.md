# Configurador RACKSA ECUADOR

App instalable del configurador de bodegas. Funciona sin internet una vez instalada.

En la tablet: abrir el enlace de GitHub Pages en Chrome → menú ⋮ → «Instalar app».

Estos archivos se generan con `python build_app.py` en la carpeta del configurador; no se editan a mano.

Enlace: https://anthonymoreira124-bit.github.io/Configurador-Racksa/
